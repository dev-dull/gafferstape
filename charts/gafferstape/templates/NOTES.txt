{{- if and .Values.tokens.create (not .Values.tokens.existingSecret) }}

WARNING: tokens.create is true. The session cookies are stored in the
Helm release history (visible via `helm get values --all`). For
production, create the Secret outside Helm and set tokens.existingSecret.
{{- end }}

To rotate cookies (every ~25 days):

  1. Capture fresh values from a Firefox login at https://my.gaf.energy
     — see docs/setup.md §1 in the repo for the steps.

  2. Update the Secret:

       kubectl create secret generic {{ include "gafferstape.secretName" . }} \
         --namespace {{ .Release.Namespace }} \
         --from-literal=session-token=NEW_SESSION_JWT \
         --from-literal=csrf-token=NEW_CSRF_VALUE \
         --dry-run=client -o yaml | kubectl apply -f -

  3. Restart the deployment so the new env vars are picked up:

       kubectl rollout restart deployment/{{ include "gafferstape.fullname" . }} \
         --namespace {{ .Release.Namespace }}

The Prometheus alert `GafferstapeSessionExpiringSoon` (in
examples/alerts.yaml) fires 3 days before expiry as a reminder.

Set `reloader.enabled=true` to have stakater/reloader (if installed)
trigger the rollout automatically on Secret changes — skipping step 3.
